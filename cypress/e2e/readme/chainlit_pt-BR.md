# Bem-vindo ao Chainnext! 🚀🤖

Olá, desenvolvedor! 👋 Estamos empolgados em tê-lo a bordo. O Chainnext é um framework compatível com Chainlit, projetado para ajudá-lo a prototipar, depurar e compartilhar aplicativos construídos em cima de LLMs.

Instale o pacote PyPI com `pip install chainnext`. No código, continue usando `import chainlit` e o CLI `chainlit` — esses nomes não mudam por compatibilidade.

## Links úteis 🔗

- **Repositório:** [chainnext no GitHub](https://github.com/Puyanfar/chainnext)
- **Documentação:** A documentação da API do Chainlit ainda se aplica 📚

Mal podemos esperar para ver o que você cria com o Chainnext! Boa codificação! 💻😊

na raiz do seu projeto. Se você não quiser uma tela de boas-vindas, basta deixar este arquivo vazio.
